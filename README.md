# 莨珠记 · 云纱智境 —— 香云纱非遗数字研学平台

> 非遗传承 · 数字体验 · 工匠育人

一个基于 **HBuilderX 5+ App（DCloud）** 的香云纱非遗数字研学平台，采用 HTML/CSS/JavaScript 构建，可打包为安卓 APK，也可直接在浏览器运行。项目围绕香云纱「三蒸九煮十八晒」染整工艺，融合**游戏化闯关、签到、成就、积分、证书**体系，并通过后端 API 与 **UE 虚拟引擎**实现虚实结合的研学体验。

> **v2.1 配色统一**：全站色板回归非遗原色 —— 丝绸米白底（#F6F0E6）+ 暖白圆角卡片 + 茶褐（#83533B）竖条分组标题 + 香云金（#D9AD71）点缀 + 草地绿（#667B55）辅助，配有一整套 **47 枚等距 3D 拟物 SVG 图标**（v4.4：青绿+橙黄两主色、奶白亮面、软圆角、加厚体块，纯矢量离线可用）。首页按「搜索胶囊 → 大 Banner → CTA 小卡 → 资讯条 → 3D 图标分区网格 → 图文卡 → 路线推荐」重构，共 28 个可点击入口。设计预览见 `docs/preview/`。

## 一、项目定位

本项目服务于职业技能大赛，由「职中老师 + 代码组同学 + UE 虚拟引擎组同学」三方协作：

| 角色 | 分工 |
|---|---|
| 指导老师 | 项目统筹、需求与内容审定 |
| 代码组 | HBuilderX 5+ App 前端 + FastAPI 后端 |
| UE 组 | 香云纱数字孪生场景（晒场、工坊、河涌等） |

前端与 UE 通过 RESTful API 完成数据互通：UE 场景中完成的工艺操作，实时回传至后端，手机端即可看到虚实联动的学习记录。

13. **教学管理端**（老师专属）—— 班级总览 / 学员管理 / 任务进度 / 成绩分析 / 内容审核
14. **我的学习** —— 装扮系统、学习报告（雷达图）、可点击成就墙、证书
15. **研学证书** —— 完成全部任务后生成结业证书
16. **设置页** —— 顶部三个快捷大按钮（**改信息 / 换头像 / 退出**）+「账号与身份」分组（**更换个人信息、更换头像、进入教学管理端、退出登录**）+ 装扮与奖励 7 个入口 + 7 个通用开关 + 通知管理 + 数据导出/重置 + 隐私政策/权限 + 帮助/关于/检查更新

  - 🖐️ 涂河泥体验（Canvas 涂抹）
  - 🫧 煮绸节拍（节奏点击）

  - 🃏 翻牌记忆（配对香云纱图案）

### 交互特效
- 点击涟漪、卡片 3D 倾斜跟随、滚动进入动画、下拉刷新、彩带粒子
- 全部为渐进增强，不支持时功能照常可用，尊重 `prefers-reduced-motion`

### 🔌 数字孪生 WebSocket 双向通信（后端 v1.3.0）
- `backend/realtime.py`：`/ws/ue/{session_id}?role=h5|ue`，按会话分房间
  - **H5 → UE**：`command`（`start_drying` / `set_weather` / `collect_cloth` / `move_camera`…）
  - **UE → H5**：`telemetry`（光照 lx / 湿度 % / 气温 ℃ / 风速 / 降雨 / 点位）持续上报
  - **UE → H5**：`ack` 指令回执；另有 `presence` 在线状态、心跳、指数退避自动重连
  - 新 H5 连入自动 replay 最近一帧遥测；REST 兜底 `/api/ue/telemetry`、`/api/ue/command`、`/api/realtime/status`
- `js/api.js` 封装 `connectWS / sendCommand / getTelemetry / on(evt,cb)`
- `js/realtime.js` 把遥测渲染成实时环境卡片，并**动态生成情境题**（下雨→立即收布 / 光照不足→暂缓摊晒 / 晴天→平铺绷紧），题目实时进入答题流程计分

### 🤖 大模型 RAG 问答
- `backend/rag.py`：18 条知识语料 → 领域词门槛 + 字符 bigram + 同义词扩展 + 点位加权检索 → Top-K 片段
- 生成层调用 **OpenAI Chat Completions 兼容**的国产大模型（智谱 GLM / 通义千问 / DeepSeek，换 `.env` 即可）
- **多轮对话**（history 保留最近 6 条、上一轮问题参与指代消解）、**引用来源**、防幻觉 system prompt、`temperature=0.3`
- **无 Key / 超时 / 异常自动降级**本地检索，前端显式标注「本地检索降级」，现场演示不中断
- 详见 `docs/03_WebSocket与大模型RAG接入.md`

### 3D 图标系统（v4.4，对齐参考图的等距拟物）
`js/icons3d.js` 内置 **47 枚按参考图重画的等距 3D 拟物 SVG 图标**。几何本身是立体物件：**亮色顶面 + 圆角主色正面 + 暗色右侧面**，再由渲染层统一补厚度与光影。覆盖首页/地图/任务/知识/我的/百科/商店/盲盒/签到/成就/证书/UE/设置/游戏/实时通道等全部入口。

- **配色收敛**：只用 `teal` 青绿 `#4CC7B7`、`gold` 橙黄 `#FFB32E` 两组主色 + `cream` 奶白亮面 + `coral` 珊瑚点缀（旧色键做别名兼容）。每枚图标主色二选一，另一色作点缀，整体高度统一
- **三色阶**：色组格式 `[亮顶面, 主正面, 暗侧面]`；占位符 `{L}{M}{D}{W}{A}{AL}{AD}` 在 `svg()` 里替换。A 表每条为 `[主色键, 点缀色键, SVG 图形]`，改图标只改这一条
- **渲染层统一增强**（`svg()`，47 枚同时受益）：
  - 同色 `stroke-width=3 + stroke-linejoin=round` → 尖角变软边黏土感
  - 右下暗面副本（+2px）与顶面亮边副本（−3px）→ 明确体块厚度；两者各带**渐变遮罩**，只保留下半/上半，避免圆形图标出现整圈白边
  - `clipPath` 轮廓内叠奶白柔光斑 + 上亮下暗渐变 → 大面积亮面
  - 顶面白色高光弧、浅灰柔和接地阴影、`viewBox 3 3 58 58` 让物件饱满占格
- **部件细节**：首页高频入口（home/map/task/know/me/game/checkin/shop/box/ai/enc/cert）额外补了门窗、勾线、按钮、刻度等小部件
- **纯本地矢量**：不依赖 CDN、不依赖图片字体，打包成 APK 后离线可用，任意缩放不失真
- **全站自动升级**：`Icon3D.upgrade()` 用 MutationObserver 增量扫描，把老页面里的 emoji 图标自动替换为 3D 图标；同时给一级页面页头补一枚主题图标
- **调用方式**：`Icon3D.svg("map")` 返回 SVG 字符串，`Icon3D.box("map", 56)` 返回带尺寸的图标盒；支持 `data-icon="shop"` 显式指定或按 emoji 自动推断
- 全览见 `docs/preview/08_3D图标放大预览.png`（47 枚）

> 说明：参考图为 3D 渲染稿（连续渐变 / 环境光遮蔽 / 真实高光），纯矢量 SVG 只能做有限色阶，风格接近但不等同于渲染级质感。

## 四、快速开始

### 方式一：浏览器直接运行（无需后端）
直接用浏览器打开 `index.html` 即可体验全部功能，数据保存在浏览器 localStorage（离线模式）。

### 方式二：HBuilderX 打包为 App
1. 打开 HBuilderX → 文件 → 导入 → 选择本项目目录
2. 运行 → 运行到手机或模拟器（可实时预览）
3. 发行 → 原生 App 云打包（生成 APK）

### 方式三：启用后端（含 UE 联动）
1. 双击 `start_backend.bat`（或 `cd backend && python run.py`）
2. 后端启动于 `http://127.0.0.1:8000`
3. 打开前端，将自动探测并连接后端
4. 接口文档：`http://127.0.0.1:8000/docs`
