# 学生安装运行指南

本指南面向竞赛小组中负责代码的同学，介绍如何运行、打包和调试「莨珠记·云纱智境」。

## 一、环境准备

| 工具 | 用途 | 版本要求 |
|---|---|---|
| HBuilderX | 5+ App 开发与打包 | 最新版 |
| 浏览器 | 网页预览（Chrome / Edge） | 现代内核 |
| Python | 运行后端（可选） | 3.10+ |
| 安卓手机 | 真机预览 / 打包安装 | Android 8+ |

---

## 二、直接预览（最简单）

用浏览器打开项目根目录的 `index.html`，即可体验全部功能（离线模式，数据存本地）。

> 注意：浏览器预览时「扫码」为演示模拟；真机打包后才可调用真实扫码模块。

---

## 三、HBuilderX 运行

1. 打开 HBuilderX
2. 菜单「文件」→「导入」→「从本地目录导入」→ 选择本项目文件夹
3. 菜单「运行」→「运行到浏览器」或「运行到手机或模拟器」
4. 手机需开启 USB 调试，HBuilderX 会自动安装基座

---

## 四、打包为 APK

1. 菜单「发行」→「原生 App-云打包」
2. 勾选 Android，填写应用名称「莨珠记·云纱智境」
3. 包名默认 `com.yunsha.langzhuji`
4. 云打包需登录 DCloud 账号，等待打包完成后下载 APK

> 如需本地打包，可参考 HBuilderX 官方文档配置 Android Studio 离线打包。

---

## 五、启用后端（含 UE 联动）

1. 双击项目根目录 `start_backend.bat`
2. 看到 `Uvicorn running on http://0.0.0.0:8000` 表示启动成功
3. 前端会自动探测后端并切换为在线模式
4. 打开 `http://127.0.0.1:8000/docs` 查看接口文档

> 若需让手机访问局域网后端，需把 `js/api.js` 中的 `API.base` 改为 `http://[电脑局域网IP]:8000`。

---

## 六、与 UE 组同学联调

1. UE 组同学启动后端，获取会话编号
2. 在 UE 场景中完成工艺操作，POST 到 `/api/ue/events`
3. 手机端「我的学习 → 学习报告」或「UE 虚实联动」页可看到联动记录

详见 `docs/02_API接口与UE4联调.md`。

---

## 七、常见问题

| 问题 | 解决 |
|---|---|
| 打开白屏 | 检查浏览器内核是否支持 async/await，换用现代浏览器 |
| 后端连不上 | 检查后端是否启动、端口是否被占用 |
| 数据不保存 | 确认浏览器未开启无痕模式 |
| 打包失败 | 检查 HBuilderX 是否登录、云打包额度 |

---
