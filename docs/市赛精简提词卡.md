# 市赛精简版脚本 + 提词卡（15分钟）

> 职中市赛 · 新一代信息技术赛道 · 4人团队
> 每人只讲自己的几句，边操作边讲，不用背长文。

---

## 一、时间分配（总约15分钟）

| 环节 | 谁讲 | 时长 |
|---|---|---|
| 开场+背景 | 队长/代码 | 1.5 分钟 |
| UE场景+演示 | UE A | 3 分钟 |
| UE材质灯光 | UE B | 2 分钟 |
| 代码三技术点 | 你 | 4 分钟 |
| 展示视频 | 视频 | 2 分钟 |
| 亮点总结 | 队长/代码 | 1.5 分钟 |
| 缓冲/提问 | 全队 | 1 分钟 |

你（代码位）只需要讲 4 分钟，而且是对着屏幕边点边讲。

---

## 二、各人讲解词（精简口语版）

### 开场（1.5分钟）

> "各位评委好，我们是莨珠记团队，项目是《莨珠记·云纱智境》，一个香云纱非遗数字研学平台。
>
> 香云纱是顺德的国家级非遗，要经过'三蒸九煮十八晒'。我们想解决研学里的三个问题：工艺难懂、学完没反馈、虚拟体验和真实数据对不上。下面开始介绍。"

### UE A（3分钟）

> "我负责UE数字孪生场景，还原了主馆、工作坊、晒莨场、河涌四大点位。
>
> 可以在里面驱动天气、摊布、收布这些操作，数据会实时传给手机端。
>
> 【演示：晴天摊布 / 下雨收布】大家看，我这边一操作，手机立刻收到变化和任务。"

### UE B（2分钟）

> "我负责材质、灯光和渲染，重点还原薯莨水色泽、河泥质感和布匹正反异色，同时配合前端联调，保证数据能被正确接收。"

### 你 · 代码位（4分钟，核心）

> "我负责前端和后端。前端用 HBuilderX 5+ App，HTML、CSS、JS 写的，能浏览器跑也能打包APK，一共17个页面；后端用 Python FastAPI 加 SQLite。
>
> 重点讲三个点：
>
> **第一，虚实联动。** 手机和UE用WebSocket双向连接，UE上报环境数据，我实时显示，还会根据天气自动出题——下雨就弹'收布'，晴天就提示'摊布'。
>
> 【演示：展示实时卡片，配合UE触发变化】
>
> **第二，大模型问答。** 我把18条专业知识做成本地库，先检索再让大模型回答，能标来源、防胡编；没网就自动降级成本地检索，演示不中断。
>
> 【演示：问"香云纱为什么用河泥"】
>
> **第三，离线兜底。** 后端断了自动切本地存储，功能照常能用，现场不会翻车。"

### 视频位（2分钟）

> "我负责视觉物料和展示视频，包括启动页动效和研学短片。
>
> 【播放30-60秒展示片】"

### 亮点总结（1.5分钟）

> "总结四个亮点：真场景，对应真实基地、44张真实照片；真联动，UE和手机实时通信；真闭环，学练考评加证书完整；真可靠，能降级、能离线，稳定演示。
>
> 介绍完毕，请老师提问。"

## 三、你的提词卡（代码位，打印成小卡片）

> 只记关键词，用自己的话讲：

```
【前端】5+App / HTML CSS JS / 17页 / 能打包APK
【后端】FastAPI + SQLite

① 虚实联动
   WebSocket双向 → 实时数据 → 看天气自动出题
   （下雨=收布 / 晴天=摊布）

② 大模型问答
   先检索本地库 → 再生成 → 标来源防幻觉
   没网自动降级

③ 离线兜底
   后端断 → 切本地存储 → 不翻车
```

## 四、开场+结尾（背熟这两句，最容易紧张的地方）

**开场：**
> "各位评委好，我是团队的前后端开发，负责平台页面、接口和UE实时通信。"

**结尾：**
> "我的部分就这些，感谢老师。"

## 五、练习计划（3-5天就能下来）

1. 把提词卡打印出来，就记上面的关键词
2. 打开项目，边点边讲，每个技术点练5遍
3. 卡壳就看卡片，不追求跟稿子一字不差
4. 录一遍音，听哪里结巴
5. 全队合练2次，卡好15分钟
6. 开场结尾背熟，中间看卡片+看界面讲

## 六、忘词救场（现场用）

- 点一下屏幕切个页面，给自己2秒
- "刚才说到……"自然停顿
- 大方看一眼提词卡，抬头接着讲
- 不会的问题："这个我还在深入学习，我的理解是……"，别瞎编
