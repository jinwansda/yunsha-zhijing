# 零基础跑通后端与大模型（保姆级）

> 适合：只有一份网页文件夹、没怎么用过命令行的同学。  
> 目标：让网页右下角的「AI 问答」真正调用大模型，而不是只查本地资料。  
> 全程只需要 **装一次 Python + 申请一个免费 Key + 双击一个 bat**，不用懂代码。

---

## 先搞懂：你手里其实有「两个东西」

| 东西         | 是什么                                  | 在哪                                         |
| ---------- | ------------------------------------ | ------------------------------------------ |
| **前端（网页）** | 你平时双击 `index.html` 看到的界面             | 项目根目录的 `index.html`、`js/`、`css/`、`assets/` |
| **后端（服务）** | 一个躲在电脑后台运行的小程序，负责「AI 问答」和「和 UE 实时联动」 | 项目里的 `backend/` 文件夹                        |

- 平时只看网页，**不需要后端**也能点来点去，只是「AI 问答」会退化成查本地资料。
- 想用**真正的大模型**回答，就必须把后端跑起来，并给它一个「Key」（相当于给 AI 的账号密码）。

下面按顺序做，一步都别跳。

---

## 第 1 步：安装 Python（只装一次）

1. 打开浏览器，访问：**<https://www.python.org/downloads/windows/>**
2. 点页面最上面黄色的按钮 **「Download Python 3.13.x」**（数字大一点没关系，3.10 以上就行）。
3. 下载完，双击那个 `.exe` 安装包。
4. **⚠️ 最关键的一步**：安装窗口**最下面**有一个勾选框  
   **☑ Add python.exe to PATH**  
   **一定要勾上！** 然后点 **「Install Now」**。  
   （不勾这个，后面 bat 会提示"找不到 Python"。）
5. 等它装完，点 **Close**。

**验证有没有装好：**

- 按键盘 `Win + R`，输入 `cmd`，回车，会弹出一个黑色窗口。
- 输入这行，回车：
  ```
  py --version
  ```
  看到类似 `Python 3.13.1` 就成功了。  
  （如果提示 `'py' 不是内部或外部命令`，再试 `python --version`；两个都不行就回到第 4 步，重装并确认勾了 PATH。）

---

## 第 2 步：安装依赖包（不用手动装，bat 会帮你装）

> 依赖 = 后端要用的几个"零件"。这一步**不用你动手**，双击 bat 时会自动装。  
> 但如果你想知道手动怎么装，或者 bat 装失败了，可以看这里：

在 `backend` 文件夹里手动装：

1. 打开项目里的 `backend` 文件夹。
2. 点一下文件夹**顶部的地址栏**，把里面的路径删掉，输入 `cmd`，回车。
3. 在黑窗口里输入（复制粘贴进去，回车）：
   ```
   py -m pip install -r requirements.txt
   ```
4. 如果下载很慢/报错，换成国内镜像再来一次：
   ```
   py -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
   > 小知识：如果这台电脑没有 `py` 命令，把上面命令里的 `py` 换成 `python` 即可。

看到最后一行是 `Successfully installed ...` 就 OK。

## 第 3 步：申请一个免费的大模型 Key（智谱 GLM-4-Flash）

智谱的 **GLM-4-Flash** 目前**免费**，最适合学生练手。跟着点：

1. 浏览器打开智谱开放平台：\*\*<https://bigmodel.cn\*\*（会自动跳到> `open.bigmodel.cn`）。
2. 点右上角 **「注册 / 登录」**，用**手机号**注册（收个验证码，设置密码）。
3. 登录后，按提示做 **实名认证**（个人认证，支付宝刷脸最快）。
   > 没实名也能用，但实名后额度和权限更完整。跟着页面点就行。
4. 进入**控制台**，在**左侧菜单**找到 **「API 密钥管理」**（有的页面叫「API Keys」）。  
   也可以直接打开这个网址：**<https://bigmodel.cn/usercenter/proj-mgmt/apikeys>**
5. 点 **「添加新的 API 密钥」**（或「新建 API Key」）。
6. 随便起个名字，比如 `yunsha`，点 **确定**。
7. 页面会弹出一长串字母数字（就是 Key）。**马上复制它！**
   > ⚠️ 这个 Key **只显示一次**，关掉就找不回了。先粘贴到记事本里存着。  
   > ⚠️ Key 相当于密码，**不要发到群里、不要截图外传**。

> 备选平台（都免费/便宜，接口都兼容，以后想换再说）：
>

> - 阿里云百炼（通义千问）：新用户每个模型送 100 万 token

## 第 4 步：把 Key 填进 `.env` 文件

我已经帮你把配置文件建好了，就在 **`backend/.env`**，你只需要改**一行**：

1. 打开 `backend` 文件夹，找到 **`.env`** 这个文件。
   > 看不到 `.env`？可能是"隐藏了已知文件扩展名"。直接右键 → 打开方式 → **记事本**。  
   > 或者：资源管理器顶部「查看」→ 勾选「文件扩展名」和「隐藏的项目」。
2. 用**记事本**打开它，找到这一行：
   ```
   LLM_API_KEY=
   ```
3. 把你刚才复制的 Key，**粘贴到等号 `=` 的后面**，变成这样：
   ```
   LLM_API_KEY=abc123def456....（你那一长串，中间不能有空格、不能换行）
   ```
4. **保存**（Ctrl + S），关闭记事本。

> 注意：
>
> - 等号后面**不要加引号、不要加空格**。
> - 如果粘贴后 Key 跑到第二行去了，说明多按了回车，删掉换行让它合到一行。
> - 暂时没有 Key 也没关系，先留空，第 6 步照样能开网页，只是 AI 走本地检索。

## 第 5 步：启动后端（双击一个 bat 就行）

1. 回到**项目根目录**（就是有 `index.html` 和 `start_backend.bat` 的那一层）。
2. **双击 `start_backend.bat`**。
3. 会弹出一个黑色窗口，自动做三件事：
   - 自动挑一个**真能跑起来**的 Python（你电脑上装了好几个也没关系，它会一个个试）
   - 缺依赖就自动装（第一次会下载一会儿，耐心等，别关窗口）
   - 启动后端
4. 看到这样的字，就成功了：
   ```
   ==========================================
      莨珠记 - 云纱智境 后端服务启动器
   ==========================================

   [2/3] 已选定的 Python：
         路径：C:\...\python.exe
         版本：3.13.14
         依赖齐全 OK

   [3/3] 启动后端...
   ========================================================
     莨珠记 · 云纱智境 后端服务
     网页地址    http://127.0.0.1:8000
     大模型      已启用  glm-4-flash      ← 说明 Key 生效了
   ========================================================
   INFO:     Uvicorn running on http://0.0.0.0:8000
   ```
   - 如果显示 **「未配置密钥（自动降级为本地知识检索）」**，说明第 4 步的 Key 没填好，回去检查 `.env`。
   - 只要看到 `Uvicorn running on http://0.0.0.0:8000`，就说明服务真的起来了。
5. **这个黑窗口不要关！** 关了后端就停了。用完再关。

> 双击后窗口一闪就没？  
> 你不会看到报错——因为脚本最后有 `pause`。如果真闪退了，说明连 Python 都没找到，
> 按 `Win+R` 输入 `cmd`，拖入 `start_backend.bat` 回车，就能看到完整提示。

## 第 6 步：让网页连上后端（两种方式，任选一种）

### 方式 A（最推荐，什么都不用配）：直接用后端的网址打开网页

后端已经把整个网页一起托管了，你只要在浏览器地址栏输入：

```
http://127.0.0.1:8000
```

回车，会直接打开你的网页，而且**自动连上后端**（同一个地址，不存在跨域问题）。  
以后每次演示，都开这个网址就行。

### 方式 B：照旧双击 `index.html`

我改过前端代码，双击打开时会**自动去找本机 8000 端口的后端**。  
所以「先开 bat → 再双击 index.html」也能连上。

> 两种都行。**答辩/演示时建议用方式 A**，最稳。

## 第 7 步：怎么确认真的连上了？（自检）

1. 网页里点进 **「AI 问答」**，问一句：
   > 香云纱为什么要过河泥？
2. 如果回答开头带着**引用来源**、内容像"人话"推理，并且右上角/设置里显示 **「后端服务：已连接在线」**，就成功了。
3. 也可以直接用浏览器打开：**<http://127.0.0.1:8000/docs>**  
   能看到一堆接口列表（Swagger 文档页），说明后端活着。
4. 想验证大模型是否启用，看黑窗口开头那行：
   - `大模型 已启用 glm-4-flash` → 用的是真大模型 ✅
   - `未配置密钥` → 用的是本地检索（功能也能用，只是没那么"聪明"）

## 常见问题排查（对着找）

| 现象                             | 原因                     | 怎么办                                                 |
| ------------------------------ | ---------------------- | --------------------------------------------------- |
| 双击 bat 一闪就没了                   | 没装 Python / 没勾 PATH    | 回第 1 步重装，勾 `Add python.exe to PATH`                 |
| `'py' 不是内部或外部命令`               | 没装 py 启动器              | 命令里把 `py` 换成 `python`                               |
| `pip` 下载卡住/报错                  | 网络问题                   | 加清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 网页能开，但 AI 说"本地检索降级"            | Key 没填 / 没保存 / 填错      | 检查 `backend/.env` 里 `LLM_API_KEY=` 后面有没有 Key        |
| 黑窗口报 `401`                     | Key 填错了（多了空格/不完整）      | 重新复制 Key，等号后不要有空格                                   |
| 黑窗口报 `429`                     | 免费额度用完 / 调用太频繁         | 等一会儿再试，或换 DeepSeek                                  |
| 打开 `127.0.0.1:8000` 打不开        | 后端没启动 / 关了窗口           | 重新双击 `start_backend.bat`，别关黑窗口                      |
| 端口被占用 `address already in use` | 上次的后端还开着               | 关掉之前所有的黑窗口，或重启电脑                                    |
| 网页样式乱了                         | 用 `file://` 直接打开时的路径问题 | 改用方式 A：`http://127.0.0.1:8000`                      |
| 装完了却**没有** `Uvicorn running`     | 只是装了包，没走到启动那一步         | 关掉窗口重新双击 `start_backend.bat`，看最后有没有 `[3/3]`         |
| `ImportError: DLL load failed ... 应用程序控制策略已阻止此文件` | Windows 安全策略拦了刚下载的 .dll（常见于首次安装） | 再双击一次 bat（脚本会自动重试）；仍不行就关掉「智能应用控制」，或改用 python.org 官网版 |
| `[ERROR] No runtime installed that matches 3.13` | 你电脑上没有这个具体版本 | 正常现象，脚本会自动跳到下一个，不用你处理 |
| bat 窗口里中文是乱码 / 报 `'orlevel' 不是内部或外部命令` | bat 文件的换行/编码被改坏了 | 用我给的原始 `start_backend.bat`（GBK + CRLF），别用记事本另存 |
| AI 只会回「没有足够资料」「本地检索」 | ① 问的是闲聊/常识，被当成"资料未覆盖"；② 页面比后端先打开，前端以为离线 | 新版已修：闲聊也走大模型。**改过后端代码要关掉黑窗口重新双击 bat**，网页按 F5 刷新 |

## 不是只能本地！三种运行范围，按场合选

先说结论：**这个项目天生就不限制在本地**，后端监听的是 `0.0.0.0`（所有网卡都收），只要地址填对，手机、别的电脑、甚至公网都能访问。区别只是「别人怎么找到你这台电脑」。

| 范围 | 谁能访问 | 需要什么 | 适合场景 |
|---|---|---|---|
| ① 本机 | 只有你这台电脑 | 什么都不用做 | 自己开发调试 |
| ② 局域网 | 同一 WiFi 下的手机/电脑 | 电脑 IP + 防火墙放行 | **比赛现场演示最稳**（没网也行） |
| ③ 公网 | 任何有网的人 | 内网穿透 或 云服务器 | 评委在自己手机上扫码看、提前线上评审 |

### 全局只有一个开关：`js/config.js`

我把「去哪个地址找后端」抽成了一个文件，以后换环境**只改这里一行**：

```js
var APP_CONFIG = {
  SERVER: "",        // 留空 = 自动（本机 / 同源）
  ...
};
```

- **留空**：自动判断。双击 `index.html` → 找本机 8000；用 `127.0.0.1:8000` 或 `手机IP:8000` 打开 → 同源直连。日常不用管。
- **填局域网地址**：`SERVER: "http://192.168.1.23:8000"` → 打包成 APK 后能连你电脑的后端。
- **填公网地址**：`SERVER: "https://xxx.cpolar.cn"` → 上线后所有人都能用。

> 改完保存 → 网页 `Ctrl + F5` 强刷；**APK 必须重新打包**才生效。

### ② 局域网（推荐用在现场答辩）

1. 电脑和手机连**同一个 WiFi / 同一路由器**。
2. 电脑 `cmd` 里 `ipconfig`，抄下 **IPv4 地址**（本机示例：`172.16.13.169`）。
3. 保持黑窗口开着，手机浏览器打开 `http://172.16.13.169:8000`。
4. 手机弹「是否允许访问本地网络」→ 允许；电脑弹防火墙提示 → 勾「专用网络」允许。

打不开的三种常见原因：

- **防火墙拦了**：Windows 安全中心 → 防火墙 → 允许应用通过 → 勾上 Python。
- **学校 WiFi 开了「AP 隔离」**（同一 WiFi 设备之间互相看不见，校园网很常见）：换成手机开热点、电脑连热点，用热点网段的 IP。
- **IP 抄错了/变了**：路由器重新分配 IP 会导致地址变化，重启后再查一次。

### ③ 公网 A：内网穿透（零成本，10 分钟搞定，适合临时演示）

原理：在你电脑上跑一个小工具，把公网域名转发到本机 8000。

1. 注册 **cpolar**（https://www.cpolar.com）或 **natapp**（https://natapp.cn），都有免费隧道。
2. 下载 Windows 客户端，按官网给的命令启动，例如：
   ```
   cpolar http 8000
   ```
3. 它会打印一个公网地址，形如 `https://a1b2c3.cpolar.cn`。
4. 把这个地址发给别人，手机 4G/5G 也能打开。
5. 想装进 APK 就把它填进 `js/config.js` 的 `SERVER`，重新打包。

注意：免费版域名**重启会变**，且电脑必须开着、黑窗口不能关。正式比赛前建议多演练一次。

### ③ 公网 B：云服务器（长期稳定，要花钱）

1. 买一台最便宜的云服务器（阿里云/腾讯云学生机，几十块一年），系统选 **Ubuntu**。
2. 安全组/防火墙**放行 8000 端口**。
3. 上传整个项目文件夹，装 Python 和依赖：
   ```
   sudo apt update && sudo apt install -y python3 python3-pip
   pip3 install -r backend/requirements.txt
   ```
4. 在 `backend` 目录后台常驻启动：
   ```
   nohup python3 run.py > app.log 2>&1 &
   ```
5. 浏览器访问 `http://服务器公网IP:8000` 就能用了。
6. 想用域名 + https：装 Nginx 反向代理到 8000，再申请免费证书（Let's Encrypt）。

> 云上跑 = 你的智谱 Key 也放在云上，**记得在智谱控制台设额度上限**，别被人刷。

### 打包成 APK 时特别注意

- 必须先在 `js/config.js` 里把 `SERVER` 填成**手机能访问到的地址**（局域网 IP 或公网域名）。不填的话 APP 会去连 `127.0.0.1`，那是手机自己，必然连不上。
- 用 `http://` 明文地址时，部分安卓版本会拦「明文流量」，优先用 https（内网穿透/云服务器都能给 https）。
- 网页版（浏览器打开）永远是最省事的演示方式，**APK 只是加分项**，别为了打包耽误主流程。

## 我（这次的改动）帮你做了哪些事

为了让你少踩坑，我把项目改了两处，你不用管，知道就行：

1. **后端直接托管网页**：改了 `backend/main.py`，让 `http://127.0.0.1:8000` 能打开整个网页（原来只返回 index.html，js/css/assets 会 404，页面是坏的）。现在一个地址全搞定。
2. **前端自动找后端**：改了 `js/api.js`，无论你是"双击 index.html"还是"用 8000 网址打开"，都能自动连上本机后端。
3. **启动器更傻瓜**：重写了 `start_backend.bat` + `backend/run.py`
   - 自动在你电脑上多个 Python 里挑**真能用的那个**（用"跑一句代码看输出"的方式验证，不靠猜）

   - 端口被占用、缺依赖、被拦截，都给中文提示 + 具体解决办法，不再是一屏红色英文
4. **配好了 `.env` 模板**：`backend/.env` 已建好，你只改 `LLM_API_KEY=` 一行。
5. **新增 `js/config.js`**：把「后端地址」抽成一个开关，本地/局域网/公网/APK 全靠它一行切换；`js/api.js` 已按它自动选地址（同源 → 同主机 8000 → 本机 8000，逐个试）。
